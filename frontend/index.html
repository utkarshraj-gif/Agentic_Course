Installation

No API keys required. The entire course runs offline using deterministic heuristics.

# Create and activate virtual environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt

# Run all 19 tests
python -m pytest -q tests

# Run all 12 class examples
python -m classes.class01_intro_agentic_ai.example

# Run a capstone project
python -m projects.clinical_prior_auth.run
python -m projects.legal_contract_review.run
python -m projects.aiops_agents.run
python -m projects.inventory_planner.run
